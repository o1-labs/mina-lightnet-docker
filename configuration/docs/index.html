Mina Lightnet

Lightweight Mina blockchain network in a single Docker container — for zkApp development and testing.

Connect Endpoints Env Vars Accounts Explorer Home Changelog GitHub

Connect Your App

This container is already running. Point your app at the GraphQL endpoint:

http://127.0.0.1:8080/graphql

o1js

import { Mina } from 'o1js';
const network = Mina.Network('http://127.0.0.1:8080/graphql');
Mina.setActiveInstance(network);

Is it ready?

Single-node lightnet syncs in ~1–2 minutes. Check sync status:

curl -s http://127.0.0.1:8080/graphql \
  -H 'Content-Type: application/json' \
  -d '{"query": "{ syncStatus }"}' | jq -r '.data.syncStatus'
# wait for: SYNCED

Accounts Manager (port 8181)

MethodEndpointDescription
GET/acquire-accountGet an unused account (?unlockAccount=true to unlock)
PUT/release-accountReturn an account to the pool
GET/list-acquired-accountsList acquired accounts
PUT/lock-accountLock an account on the daemon
PUT/unlock-accountUnlock an account on the daemon
